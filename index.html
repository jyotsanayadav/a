FashionVision AI

Fashion attribute recognition tool · Python, C++, PyTorch

  • Built a fashion cataloging system with a C++ foundation module (tensors, SVD, gradient checking, neurons, MLP, optimizers) and deep learning models in PyTorch.
  • Trained ResNet-18 on Fashion-MNIST and compared SGD, Momentum and Nesterov optimizers.
  • Trained Mask R-CNN on ModaNet for garment detection and segmentation; transfer learning raised box AP50 from 0.7% to 19.9% in a small pilot.
  • Added a Transformer metadata model and VAE/GAN image generators, exported ResNet-18 to ONNX, and delivered a Streamlit app for detection, classification and image generation.

ResNet-18 reached 92.39% accuracy and 92.33% macro F1 on Fashion-MNIST. ONNX CPU inference ran in 2.68 ms in Python and 6.21 ms in C++.
